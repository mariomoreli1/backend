## Как запустить лабу
```
cd "07 лаба 5"
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```
Открыть http://127.0.0.1:8000. Начиная с лабы 7 есть пользователи:
модератор moderator@mail.ru / 123456, читатель reader@mail.ru / 123456.

## hw1
20 задач из ДЗ1.docx, тесты в test.py (88 штук, надо было 60+).
```
pip install pytest
cd hw1
pytest test.py
```
hw1.zip — архив для сдачи (сразу файлы, без папки).

Задачи:
1. **hello.py** — вывести "Hello, World!". `print()`.
2. **python_if_else.py** — нечёт/чёт + диапазоны → Weird/Not Weird. Цепочка if/elif/else.
3. **arithmetic_operators.py** — сумма, разность, произведение двух чисел. Три print.
4. **division.py** — целочисленное и обычное деление, проверка деления на 0. `//` и `/`.
5. **loops.py** — квадраты чисел от 0 до n-1. `for i in range(n)`.
6. **print_function.py** — напечатать 123...n без строковых методов. `print(*range(1,n+1), sep='')`.
7. **second_score.py** — второе по величине число из списка. `set` + `sorted`, `[-2]`.
8. **nested_list.py** — студент(ы) со второй по величине оценкой. Тоже через `set` оценок.
9. **lists.py** — эмулировать список команд (insert/print/remove/append/sort/pop/reverse). `getattr(arr, command)`.
10. **swap_case.py** — поменять регистр строки. `str.swapcase()`.
11. **split_and_join.py** — разбить по пробелу, склеить через дефис. `split`/`join`.
12. **max_word.py** — самое длинное слово из example.txt. Регулярка достаёт слова, знаки препинания не считаются.
13. **price_sum.py** — сумма трат по категориям из products.csv. Модуль `csv`.
14. **anagram.py** — проверка на анаграмму. Сравнение отсортированных строк.
15. **metro.py** — сколько пассажиров в метро в момент T. Перебор интервалов входа/выхода.
16. **minion_game.py** — игра Кевин/Стюарт по гласным/согласным. Подсчёт через len(s)-i, без перебора всех подстрок.
17. **is_leap.py** — високосный год или нет. Условие на делимость на 4/100/400.
18. **happiness.py** — настроение по множествам A (нравится) и B (не нравится). `set` для быстрой проверки.
19. **pirate_ship.py** — рюкзак с дробными весами (жадный алгоритм). Сортировка по цене за кг.
20. **matrix_mult.py** — перемножение матриц без numpy. Три вложенных цикла.

## hw2
17 задач, каждая — функция в отдельном файле, тесты в test.py (102 штуки, надо было 60+).
```
pip install pytest
cd hw2
pytest test.py
```
hw2.zip — архив для сдачи (сразу файлы, без папки).

Задачи:
1. **fact.py** — факториал рекурсией и циклом, сравнение скорости в комментарии.
2. **show_employee.py** — строка «ФИО: зарплата ₽», зарплата по умолчанию 100000.
3. **sum_and_sub.py** — сумма и разность двух чисел (возвращает кортеж).
4. **process_list.py** — list comprehension и генератор, сравнение скорости.
5. **my_sum.py** — сумма любого количества аргументов через `*args`.
6. **my_sum_argv.py** — то же, числа из аргументов командной строки (`sys.argv`).
7. **files_sort.py** — файлы папки, сгруппированные по расширению и по алфавиту.
8. **file_search.py** — рекурсивный поиск файла через `os.walk`, вывод первых 5 строк.
9. **email_validation.py** — проверка email регулярным выражением.
10. **fibonacci.py** — числа Фибоначчи, `map` + `lambda` для кубов.
11. **average_scores.py** — средний балл каждого студента через `zip(*scores)`.
12. **plane_angle.py** — угол между плоскостями: класс Point с `__sub__`, `dot`, `cross`.
13. **phone_number.py** — декоратор приводит номера к виду +7 (xxx) xxx-xx-xx.
14. **people_sort.py** — декоратор сортирует людей по возрасту (устойчивая сортировка).
15. **complex_numbers.py** — класс комплексного числа: + − × ÷ и модуль.
16. **circle_square_mk.py** — площадь круга методом Монте-Карло, погрешность в комментарии.
17. **log_decorator.py** — декоратор `function_logger`, пишет вызовы функции в файл.
