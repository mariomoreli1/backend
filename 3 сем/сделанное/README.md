## Как запустить тесты

```bash
python3 -m venv ve
source ve/bin/activate      # на Windows: ve\Scripts\activate
pip install pytest
cd hw1                      # важно: запускать из папки с задачами
pytest test.py
```

В начале `test.py` есть переменная `INTERPRETER`. Сейчас стоит `python3` (для Mac).
На Windows поменяй на `python`.

> Как устроены тесты: функция `run_script` запускает твой файл как отдельную программу
> (`subprocess`), «печатает» ему на вход нужные строки и ловит то, что программа вывела.
> Потом сравнивает с ожидаемым. `@pytest.mark.parametrize` — это способ прогнать один и тот же
> тест на десяти разных наборах данных, не копируя код.

## ЛР1-ЛР2 — сайт на Laravel (папка `lr1-lr2/`)

### Что такое Laravel, в двух словах

Laravel — это фреймворк на PHP, то есть готовый каркас сайта. Вместо того чтобы вручную писать
`index.php`, разбирать адреса и склеивать HTML (как в `lab9`/`lab10` 2-го семестра), ты
раскладываешь код по трём понятным местам:

```
браузер просит /  →  Route (routes/web.php)  →  Controller  →  View (Blade-шаблон)  →  HTML
```

- **Route (маршрут)** — «таблица адресов»: какой URL какой код запускает.
- **Controller (контроллер)** — класс, в котором лежит логика: достать данные, подготовить их.
- **View / Blade (шаблон)** — HTML с вставками `{{ $переменная }}`, `@foreach`, `@if`.

Это та же схема MVC, что была в `lab9`/`lab10`, только Laravel делает рутину за тебя.

### ЛР1: макет, маршруты, массив в шаблон

- `resources/views/layouts/app.blade.php` — **макет**. В нём шапка с меню, подвал с ФИО и
  дыра `@yield('content')`. Каждая страница пишет `@extends('layouts.app')` и заполняет эту
  дыру через `@section('content') ... @endsection`. Поэтому меню и подвал написаны один раз.
- `routes/web.php` — адреса `/about` и `/contacts` описаны прямо там функцией:
  `Route::get('/about', function () { return view('about'); })`.
- Для «Контактов» внутри маршрута собран PHP-массив и передан в шаблон:
  `view('contacts', ['contacts' => $contacts])`. В шаблоне он перебирается `@foreach`,
  так что добавить контакт = добавить элемент массива, HTML трогать не нужно.
- `route('about')` в ссылках — Laravel сам подставит правильный адрес по имени маршрута.

### ЛР2: контроллер и json

- Контроллер создан командой `php artisan make:controller MainController`
  (`artisan` — консольный помощник Laravel).
- `public/data/news.json` — «база данных» из файла: 4 новости с полями `title`, `date`,
  `announce`, `preview_image`, `full_image`.
- `MainController::index()` читает файл (`file_get_contents` + `json_decode` превращает
  JSON в PHP-массив) и отдаёт его в шаблон `main.blade.php`, где новости выводятся таблицей.
- Маршрут `/` теперь указывает не на функцию, а на метод контроллера:
  `Route::get('/', [MainController::class, 'index'])`.
- Картинка-превью обёрнута в ссылку на `/galery/{id}`. `{id}` — это параметр в адресе:
  Laravel передаёт его в метод `galery(int $id)`, тот находит нужную новость и показывает
  `full_image`. Если такой новости нет — отдаётся 404.
- `asset('images/...')` строит правильную ссылку на файл из папки `public`.

Задание не приложило свои картинки и json («картинки на своё усмотрение»), поэтому
картинки-заглушки и новости я сделал сам.
